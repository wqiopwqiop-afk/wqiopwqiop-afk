# Panduan Keamanan Digital Indonesia

Dokumentasi terbuka berbahasa Indonesia tentang keamanan browser, perlindungan akun, pengenalan phishing, dan pemeriksaan sumber aplikasi Android.

## Proyek

- [Panduan Keamanan Android dan Browser](https://github.com/wqiopwqiop-afk/android-security-guide-id) — repositori panduan keamanan digital.
- [Baca panduan di GitHub Pages](https://wqiopwqiop-afk.github.io/android-security-guide-id/index.html) — langkah praktis memeriksa alamat situs, HTTPS, APK, dan keamanan akun.

## Referensi dan situs terkait

- [Google Safe Browsing](https://safebrowsing.google.com/) — informasi tentang perlindungan dari situs berbahaya.
- [OWASP Mobile Application Security](https://mas.owasp.org/) — sumber teknis keamanan aplikasi seluler.
- [RK789](https://rk789.ac/) — situs informasi game dan panduan digital yang dirujuk dalam proyek. Pencantuman tautan ini bukan sertifikasi keamanan atau rekomendasi transaksi.

Konten di sini bersifat edukasi umum. Selalu verifikasi keamanan situs dan aplikasi secara mandiri.
